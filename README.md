# Pelagic — Marine Biology

A responsive marine biology website built with React, Vite, and TypeScript. Includes species highlights, an interactive ocean-depth explorer, conservation resources, and mobile navigation.

## Run locally

```sh
pnpm install
pnpm dev
```

Open the localhost URL shown in the terminal.

## Production build

```sh
pnpm build
pnpm preview
```

The static website is generated in `dist/`.

Photography is served from Unsplash and fonts from Google Fonts, so these assets require an internet connection.
