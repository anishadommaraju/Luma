# OCD evidence library

19 unique papers covering 20 requested entries. The unnumbered e-OCD review is item 20. Item 14 reuses item 2, the 2025 guideline update (published in 2026). Downloaded from PubMed Central on September 28, 2026.

Each paper has a full-text HTML copy and a readable text extraction. Citation metadata and SHA-256 checksums are in `sources.json`. HTML copies retain source copyright notices; linked figures and styles may require internet access. PDFs are not included.

## Retrieval routing

- Use `general-sources.json` for ordinary research retrieval (18 papers).
- Use `safety-sources.json` only for safety-related questions (1 paper): hopelessness, suicide, self-harm, severe depression or crisis situations.
- `sources.json` is the complete inventory, not the default retrieval list.
- These are metadata and separate manifests, not a running retrieval engine. Any future retriever must honor the routing fields.
- Pair item 16 with item 8; thought-action fusion is not specific to OCD.
- Do not infer suicidal intent from an intrusive harm thought, or individual risk from group-level statistics.
